# Toolbox_BIN

De tools die nodig zijn om ons programma te runnen zijn: Minimap2, Samtools en BCFtools.

Voordat je begint met het downloaden van de tools, zorg ervoor dat je een map hebt waar je progamma in staat. 
Geef dit een naam waarmee je de map makkelijk terug kan vinden.

Mininmap2 kun je downloaden via deze link:
https://github.com/lh3/minimap2

Zodra je Minimap2 hebt gedownload staat het in je downloads als een zip, deze pak je uit door op exstract here te klikken. 
Zorg ervoor dat je deze niet in je downloads map laat staan, hierdoor wordt het slordig en moeilijker des te meer je download.
Zet deze map in dezelfde map waar je het progamma in hebt staan.
